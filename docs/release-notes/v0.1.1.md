A patch release of Ligus (short for *ligustica*): adding a phone by scanning the desktop's code, a faster desktop launch, clearer buttons and proposals, and security and membership fixes.

## What's new in 0.1.1

- **Add a phone by scanning the desktop's code.** On the desktop, **Settings → Profile → My devices → Add a phone → Show code**; the phone scans it, you compare the fingerprint and approve with your passkey. Pasting a code still works under **Can't scan?**. The add-a-phone flow also got clearer errors, one My devices row per phone (with the box it's paired with and when it was last seen), the workspace's name instead of the box's label, and a revoke prompt that names the phone.
- **Face ID before every phone action that counts.** The phone app asks for Face ID, Touch ID or the passcode each time it signs a vote, an answer, an apply request, a lockdown clear or a box admission. Chat messages don't ask.
- **Faster desktop launch.** The desktop no longer walks your whole workspace folder before its window opens, which could take seconds in a large folder; switching workspaces is quicker too.
- **Buttons and proposals.** Buttons, links and menu items show a pointer and hover feedback. Proposal bodies, notes and agents' questions render Markdown, and a proposal you voted on says "You approved" or "You rejected", with a way to change your vote.
- **Membership fixes.** Removing a box from the relay roster also removes it from the workspace before the key rotation, so it can't read new messages. When the relay refuses a membership change (not an Admin, last Owner), the desktop stops and shows why instead of carrying on.
- **Security fixes.** Only an Admin can name the workspace; My devices trusts reports only from your own boxes; and adding a phone by QR code checks the answering desktop, sees every phone that answers a code, and looks once more before approving.
- **CLI.** `ligus help` and `--help` on every command document the CLI fully, `ligus status` summarises a data dir, read commands take `--json`, and `ligus app` opens the desktop app.
- **Smaller fixes.** Copying a code block leaves off the final newline, Settings sections fail on their own with **Try again**, warnings have their own colour, contrast fixes, and the Homebrew tap updates no longer race.

Full list: [What's new](https://docs.langstroth.ai/ligus/reference/whats-new/).

## Install or update

The desktop app updates itself. To install:

```sh
brew install --cask langstroth-ai/ligus/ligus-app   # desktop app (macOS)
brew install langstroth-ai/ligus/ligus             # CLI
```

Or download an installer below. CLI binaries come with `.sha256` checksums. With Homebrew, `brew upgrade ligus` updates the CLI.
