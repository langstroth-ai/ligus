Ligus (short for *ligustica*) 0.2.1 is a security release: a chat's history is now kept per workspace, so a member of another workspace you share can no longer hide, re-home or disturb your chats; upgrade every member of a workspace.

## What's new in 0.2.1

- **A chat's history belongs to its workspace.** Chat ids aren't namespaced by workspace, so someone in another workspace you share (an ex-member, a DM peer) who knew a chat's id could sign events under it and, on your device, decide which workspace the chat belonged to, blank it, or make your next message unreadable on other devices. Each chat's log is now kept per workspace: their events form a separate chat in their own workspace, visible only there. This fixes the known issue in 0.2.0.
- **Event ids are unique per workspace.** An event id planted first in another workspace no longer keeps the genuine event out of its chat.
- **Checks use the chat's own workspace.** The check a box runs before it applies code, and the agent access gates, read the chat in its own workspace. The chat list, the Inbox and notifications carry the chat's workspace, and the command palette opens a chat in it. Deleting a chat removes only that workspace's copy.
- **Secret redaction fails closed.** If the fast matcher can't be built, every registered secret is still masked, one at a time, instead of none.
- **A one-time database upgrade.** The first launch of 0.2.1 (desktop, `ligus serve` or a worker) upgrades the local database once. It can take a few seconds on a large history and needs about 2.5 times the database's size in free disk space; if there isn't enough, Ligus says how much to free ("free N GB ...") and changes nothing. A temporary backup is kept beside the database and removed after the next clean launch.
- **Upgrade every member.** Each device protects its own copy of a chat, so upgrade every desktop and `ligus serve` box in the workspace.

Full list: [What's new](https://docs.langstroth.ai/ligus/reference/whats-new/).

## Install or update

The desktop app updates itself. To install:

```sh
brew install --cask langstroth-ai/ligus/ligus-app   # desktop app (macOS)
brew install langstroth-ai/ligus/ligus             # CLI
```

Or download an installer below. CLI binaries come with `.sha256` checksums. With Homebrew, `brew upgrade ligus` updates the CLI.
