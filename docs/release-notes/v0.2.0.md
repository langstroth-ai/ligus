Ligus (short for *ligustica*) 0.2.0 brings a calmer desktop with an Inbox for what needs you, a model picker in every chat, the system passkey sheet on macOS, one set of CLI conventions, a more reliable event store, and security fixes; upgrade every member of a workspace.

## What's new in 0.2.0

- **A calmer desktop.** An **Inbox** gathers everything that needs you (an agent's question, a vote, a proposal ready to apply, a failed run, invites and device requests), and the dock and tray badges count only those. State that doesn't need you sits in a quiet status bar at the foot of the window, with at most one banner across the top. **Focus mode** (⌘.) hides everything but the chat. Notifications come only for what needs you, never while the window is in front, and a burst becomes one. A **Density** setting (Compact, Comfortable, Spacious), themed tooltips with shortcut chips, keyboard-first menus, a shortcuts sheet (⌘/) and one shared colour source for the desktop, the phone and `lt`.
- **Pick the model while you chat.** The route pill under the composer lists the models each runtime offers (Claude Code, Codex, Copilot CLI, Antigravity, Ollama, OpenAI-compatible servers) plus **Other…**. The choice is kept per chat, and each reply is labelled with the model it ran with.
- **Native passkey prompts on macOS.** For workspaces that use the `ligus.ai` passkey relying party (the default), the desktop asks with the system passkey sheet (Touch ID, iCloud Keychain, an iPhone nearby) instead of opening the browser. The browser stays one click away.
- **CLI standards.** `ligus doctor` runs every check and prints one `ligus.checks.v1` report (`--json` too). One exit-code table, 0 to 7, for `ligus` and the deploy scripts; `--legacy-exit-codes` keeps the old codes for this release only. Errors say what happened, why and how to fix it, with a JSON form. Common flags (`--flag=value`, `-o`, `-q`, `--color`, `--dry-run`, `ligus send --wait`), one help layout, `ligus help --json`, and zsh and fish completions for `ligus-local` and `ligus-k8s`.
- **Event-store reliability.** Writes from the phone, the desktop and sync landing in one chat at once no longer get lost or fail with "UNIQUE constraint failed" or "database is locked". Purge and prune decide under the write lock and never delete an earlier backup, and secret redaction no longer stalls while many secrets are registered.
- **Security fixes.** A proposal comment can only be posted under its signer's own name, and only verified comments reach an agent. A phone sees its own person's role and vote, not the box's. Synced avatar colours are validated. `ligus doctor`'s relay probe has a timeout and redacts what it prints, and `--dry-run` is refused where a command can't preview. Model listing runs only the harness's own binary and refuses option-like model ids. `url` is updated to 2.5.9 and sign-in links open only `http` and `https`.
- **Upgrade every member.** The comment check runs on each member's own device, so 0.1.x members can still show a forged comment. Upgrade every desktop and `ligus serve` box in the workspace.

**Known issue:** a member of another workspace you share who knows a chat's id can disturb that chat on one device. This is fixed in 0.2.1.

Full list: [What's new](https://docs.langstroth.ai/ligus/reference/whats-new/).

## Install or update

The desktop app updates itself. To install:

```sh
brew install --cask langstroth-ai/ligus/ligus-app   # desktop app (macOS)
brew install langstroth-ai/ligus/ligus             # CLI
```

Or download an installer below. CLI binaries come with `.sha256` checksums. With Homebrew, `brew upgrade ligus` updates the CLI.
